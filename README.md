# 🐾 PetOkra

PetOkra is a location-based mobile application that helps pet owners discover nearby playmates, connect with other pet owners, and arrange safe meetups.

## Vision

PetOkra aims to become the social platform for pets by starting with dog playdates and gradually expanding to all companion animals.

## Tech Stack

- Flutter
- Django REST Framework
- PostgreSQL
- Docker
- Redis
- Firebase
